This is a collection of usefull Python modules written by [@DUB1401](https://github.com/DUB1401). It provides common development instruments and [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI) abstraction systems.

Development now in beta stage, releases dropped by Rolling-model. That's mean if for improvements, fixes, optimization or stardatization backward compatibility may be disrupted it will be disrupted. Always lock lib version!

## Documentation
Automatically updated documentation available on [Read the Docs](https://dublib.readthedocs.io/ru/latest). Build insctructions you can find [there](https://github.com/DUB1401/dublib/tree/main/docs).

All functions, classes and methods in **dublib** provides detailed docstrings in [Sphinx](https://www.sphinx-doc.org/en/master) format. Use it in development process on the fly.

## Available modules
- **CLI** – instruments kit to make CLI applications and stylize text in terminal.
- **Engine** – talking bus, configs operator, patcher and localisation helper.
- **Functions** – functions to data processing and transformation, unified system calls, decorators.
- **Polyglot** – simple formatters for _Markdown_ and _HTML_.
- **TelebotUtils** – users manager based on JSON, caching operator and extensions for [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI).
- **Validators** – validators and parsers for string-type data.
- **WebRequestor** – WEB-requests operator, that unified work with [requests](https://github.com/psf/requests), [httpx](https://github.com/encode/httpx) and [curl_cffi](https://github.com/lexiforest/curl_cffi) libs and add many automations.
